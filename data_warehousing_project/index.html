European Airbnb Market Analysis

An End-to-End Data Warehousing & ETL Pipeline Project

Project Overview

This project focuses on building a beginner ETL pipeline to process and visualize Airbnb data across major European markets. The goal was to transform raw, unstructured data into a clean, query-optimized data warehouse to uncover pricing trends and occupancy rates.

Tools Used: SQL, Python, Tableau, and standard Data Warehousing architectures.
